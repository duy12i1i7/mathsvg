# Synthetic corpus

The canonical generator is
[`python/generate_synthetic.py`](../python/generate_synthetic.py); implementation
code lives in `python/mathzip_bench/synthetic.py`. Keeping generation in the
benchmark package ensures the manifest writer, verifier, and benchmark tags use
the same schema.

```bash
python3 python/generate_synthetic.py \
  --output datasets/synthetic \
  --seed 1297748005
```

Generated bytes are not committed. Every output file, seed, family, noise
density, size, and SHA-256 digest is recorded in `manifest.json`.
