# MathSVG plot package

This package supplies the required `mathsvg/python/plots` namespace. The
deterministic, code-native SVG renderer remains in
`mathsvg.python.analysis.profile_benchmark`; this directory intentionally does
not copy it. Generated evidence belongs under `mathsvg/results/plots`, never
inside this source package.

The canonical invocation is documented in
`mathsvg/docs/profiling-and-plots.md`.
