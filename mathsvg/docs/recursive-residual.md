# Recursive residual representation

## Algebraic domains

Correction layers operate in one declared domain:

- bytewise \(GF(2)^8\) for XOR;
- \(\mathbb Z/2^w\mathbb Z\) for modular add/subtract;
- a finite field with a versioned irreducible polynomial;
- sparse replacement maps over exact positions.

All operands have identical type and logical length.

## ARPL — Algebraic Residual Projection Lattice

Given a residual state \(R_j\) and a finite canonical projection catalogue
\(\Pi\):

\[
P_j=\pi(R_j),\qquad
R_{j+1}=R_j\ominus P_j.
\]

The optimiser finds:

\[
\min_{\pi_0,\ldots,\pi_k}
\left[
\sum_{j=0}^{k}L(\pi_j,P_j)
+L(\operatorname{Represent}(R_{k+1}))
\right].
\]

Projection families include constant/affine/periodic/recurrence components,
sparse support, bit-plane components, corrected copy and bounded modular
low-rank factors. A state key contains the residual digest, domain, depth and
remaining budget. Equal states are hash-consed.

## Losslessness

Each layer stores a projection node and an exact correction child. The decoder
evaluates from the deepest child outward using the inverse of the declared
group operation. XOR and modular addition/subtraction are bijections for a
fixed predictor. Sparse replacement records exact original values. Induction
on residual depth therefore gives the original root value exactly.

## Bounds and stop rule

- maximum residual depth is profile-specific;
- every new layer must beat the complete literal child by a declared safety margin;
- node/dependency/work/memory budgets are decremented monotonically;
- repeated residual digests terminate the branch;
- all candidate orders are canonical.

The encoder stops when no complete projected candidate is shorter than the
literal node or when a deterministic budget is exhausted. A budget stop is
not called optimal.

### Implemented optimizer edge and oracle gate

`mathsvg-optimizer::ResidualProvider` can submit a nonzero-depth ARPL winner as
a native interval candidate. The optimizer independently verifies the emitted
`CORRECT` tree and charges the residual engine's declared work and completeness
to its global ledger. All built-in Fast/Balanced/Max/Structured/Repository
profiles leave this provider disabled, and enabling it requires
`ArplGate::Experimental`, because the current non-synthetic oracle has not
justified default emission.

## Native leaf coding

Every refreshed residual oracle competes against the current native function
winner, whose literal catalogue is raw, byte-RLE, zero-run, sparse-zero,
bit-pack, LZ tokens, Canonical Huffman and LZ-Huffman. This matters:
headroom measured against the earlier raw literal is stale after opcode `0x06`
or `0x07` wins. External Zstd is an oracle/baseline only and is forbidden as a
Native MathSVG payload.

The canonical evidence is generated by
`python/oracle/native_probe/src/main.rs`. It records depths zero, one and two,
complete archive bytes, states, work, ledger size, budget status and heuristic
omissions. A zero bounded result closes no branch outside that declared
catalogue.

## Required evidence

- per-layer bytes, entropy, node and work counts;
- depth distribution and exact storage identity;
- paired `depth=0/1/2/...` ablation;
- per-family projection ablation;
- synthetic exact-generator proof and non-synthetic wins;
- holdout and literal-safety regression.
